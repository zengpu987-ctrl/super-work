> 本文件是这轮 UI / 交互升级的执行依据；冲突时以产品约束（离线、React + 手写 CSS、中文）为准。

## 1. 信息架构（Kimi 结论 · 已采纳）

- 工具条模式分段右侧新增「模型团队 · N」入口 → 打开 **680px 右侧抽屉**，不新增第四栏。
- 抽屉页签：**全部 / 配合 / 并行**；表格列：模型、平台、角色·模式、强度、连接、调用、操作。
- **同一模型只建一个成员**，通过多条「模式—角色」绑定复用；强度可按模式覆盖。
- **右栏「编排」仍是角色配置唯一入口**；团队只负责总览、复用与模板。未绑定角色的成员显示「待命」，
  严格不生成调用、不计入调用数。
- 工作记录保存本次团队快照、角色绑定与停止事件；模板只保存结构与参数，**不保存任何密钥**。
- 运行中使用只读快照，修改只作用于下一次任务。

## 2. 运行中单模型终止（Kimi 规格 · 已采纳）

- 参与者卡片右上角状态区，仅 `streaming` 时显示「停止」；点击热区尽量大，方框图标，
  默认低对比灰，悬停 / 聚焦浅红底红色图标；Tab 可聚焦，Enter/Space 触发。
- **不做二次确认**：影响仅限单模型且保留已有输出，弹窗会打断连续监控。
- 点击后立即禁用，显示「停止中…」；不重复提交。
- **409**：按「已停止或已结束」处理，拉取并同步最新状态，不报红色错误；
  **网络失败**：恢复按钮并提示「未能停止，请重试」。
- 停止后的卡片：中性 slate 灰 chip「已停止」，不用错误红；正文保留并标注
  「已由你停止 · 以上为部分输出」，不得标为完整回答。
- 最终答案继续等待其余参与者，并注明「{模型名}已由你停止，未纳入完整结果」；不把整体判失败。
- 三类停止的区分：单模型＝局部、中性灰；整体停止＝顶栏红色描边「停止运行」；
  预算拦截＝琥珀色系统自动触发。

## 3. 设置内置购买入口（Kimi 规格 · 已采纳）

- 位置：每个 provider 配置块**底部**，与连接测试分隔，不占页头/页签。
- 顺序：`获取 API Key` → `充值`；订阅制单独一行 `购买订阅`，不把三个按钮堆在一起。
- 计费标注：API「按量计费」；订阅「周期与额度以官方为准」；不做价格对比。
- 特例：WorkBuddy 显示「积分制、无需填写 API Key」；中转站「向服务方获取密钥与额度」，
  不提供「官方」按钮；演示模型「内置演示，无需购买或充值」。
- 外链：先展示目标域名与「即将前往第三方网站」，确认后新窗口打开（noopener noreferrer）。
- 统一文案：**「费用均由对应服务方收取，Super Work 不代收任何款项。」**

## 5. 优先级与验收（Kimi）

| 优先级 | 改动 | 验收 |
|---|---|---|
| P0 | 模型团队入口 + 抽屉 | 工具条显示去重成员数，Esc/遮罩关闭后焦点回到入口 |
| P0 | 单模型停止 | 卡片与团队抽屉都能仅用键盘停止同一模型，两处状态同步 |
| P0 | 停止后部分输出保留 | 不再追加内容，其余模型继续流式，最终答案不误报整体失败 |
| P1 | 设置购买入口 | 所有入口先显示域名确认；无静默跳转；不出现「软件代收」歧义 |
| P1 | 三类停止视觉区分 | 单模型灰、整体红、预算琥珀，文案不混用 |
| P2 | 团队模板 | 保存/套用/删除可用，模板不含密钥，套用覆盖并行+配合 |

## 6. 弱化 / 删除项（Kimi）

- 删除页头重复的购买入口，购买只存在于 provider 块底部。

- 价格/额度说明默认折叠，只显示计费类型。
