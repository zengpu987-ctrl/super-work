# Kimi K3.1 Pro · v0.0.2 最终设计规格

> 第二轮（落地规格），由 Kimi K3.1 Pro 基于第一轮评审与 v0.0.2 结构产出。

### 1. 右栏编排区
- 宽 320，内边距 12；8 槽纵向排列，折叠行高 **36px**、槽间距 **4px**。左侧 16px 展开箭头，角色名 **13px/20px、500**；右侧显示「2 模型」或灰色「未配置 · 不会调用」（11px）。
- 展开采用单槽手风琴：头部 40px；每个模型一行 **40px**，模型名单行省略，尾置 **96×24px 五段强度选择器**（仅显示 L/M/F/Mx/U，悬停出全称）；「＋模型」行 32px。
- 多模型逐行展示，不用芯片堆叠；行尾悬停出现 16px「×」，点击二次确认仅在该模型正被调用时触发。

### 2. 运行画布
- 未配置角色**不渲染灰卡**，也不留占位；工具条摘要保留「已配置 n/8」。参与者卡按调用顺序出现，同角色多模型纵向排列，卡间距 12px。
- 运行中可直接改强度：选择器立即更新，右侧出现 **12px 蓝色「下次生效」**标记，并 Toast「已更新为 Max，下一次调用生效」，持续 2 秒；当前调用参数仍在卡内显示为「本次：Medium」。失败则回滚并提示。

### 3. 产物容器
- 1024 宽时页签压缩为 **32px 高等宽三段**，保留「答案 / 图 n / 码 n」；容器不足 280px 时改为「答案｜图标 n｜图标 n」。
- 图片网格：容器 ≥720px 四列、480–719px 三列、<480px 两列；间距 **12px**，缩略图默认 **160×160px、1:1、object-fit:cover、圆角 8px**。
- 3D 工具栏：旋转/平移切换、缩放＋/－、适应视图、线框、网格/坐标轴、重置、截图、全屏；加载与 WebGL 失败态必须提供代码下载。

### 4. 资源页面
统一全屏覆盖层：页头 **56px**（返回箭头＋标题，右侧主操作）；其下 KPI 行 **96px**，4 卡等宽、间距 12；内容区最大宽 1200、边距 24、区块间距 20。空状态高 240，含图标、一句说明、主按钮。返回用左上「← 工作台」及 Esc，保留原页签、滚动位置和未保存草稿；有修改时先确认。

### 5. 强度视觉
统一五格刻度，选中格及左侧填充，文字保持中性色：
```css
--low:#64748B; --medium:#60A5FA; --fast:#3B82F6;
--max:#6366F1; --ultra:#7C3AED; --track:#E2E8F0;
```
圆角 4px、格间距 2px；不用红绿、发光或渐变。

### 6. 最容易做砸的 5 个细节
1. 把运行中改强度误写成“立即中断并重试”。  
2. 320px 右栏中模型名、删除键、选择器互相挤压。  
3. 未配置灰卡过多，画布看似运行了 8 个角色。  
4. 切换产物页签后丢失滚动、代码编辑或 3D 相机状态。  
5. 资源覆盖层返回后重置工作台，或未保存价格/步骤被静默丢弃。
