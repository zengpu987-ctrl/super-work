# Super Work 使用说明 / User Guide

> 版本 v1.0.0 Pro · 2026-11-21 · 适用于 macOS 原生壳与浏览器访问  
> 开源仓库：https://github.com/zengpu987-ctrl/super-work · 许可证 Apache-2.0

---

## 1. 五分钟启动

### 方式 A：原生 macOS 应用（推荐）

1. 下载/克隆仓库；
2. 双击根目录 `启动 Super Work.command`，或执行：
   ```bash
   bash apps/mac/build.sh --open
   ```
3. 应用会在 `127.0.0.1:7788` 拉起本机服务，并显示独立窗口；数据在 `~/.super-work/`。

### 方式 B：开发模式

```bash
pnpm install
pnpm dev          # 服务端 7788 + Vite 5178
# 打开 http://127.0.0.1:5178
```

### 方式 C：生产模式

```bash
pnpm build:all
pnpm start        # http://127.0.0.1:7788
```

首次打开没有任何 API Key 也能用：内置**演示模型**，点「演示试跑」即可看到完整的多模型联合流程。

## 3. 工作模式

### 3.1 并行 Parallel
所有选中模型同时独立作答。可指定「裁判/整合」模型把结论合成一份最终答案；不指定则按顺序拼接。适合方案对比、事实核查、多视角评审。

### 3.2 配合 Coordinate
按 8 个内置角色分工，未选中的角色严格不调用：

1. 发令官：拆任务、给约束；
2. 强推理：分析、验证、给假设；
3. 代码实现：写代码/脚本；
4. 建模：Three.js/3D；
5. 生图：图片产物；
6. Chat：轻量对话/整理；
7. 整合优化：合成初稿；
8. 裁判：最终裁决。

每个角色可多选模型、单独调档；支持创建自定义角色（名称、职责、是否生图、模型多选），与内置角色混排。

### 3.3 Chat 单模型多轮
每次只选一个模型，像聊天一样多轮对话；命令区显示上下文占用，支持「交给团队」转入并行/配合，团队结果也可切回 Chat 追问。历史多轮保留，可回看任意一轮。

### 3.4 旧版模式（API）
议会 Council、辩论 Debate、接力 Pipeline、投票 Vote、自动调度 Auto 仍可通过 `POST /api/runs` 的 `mode` 使用，界面收敛为上述 3+Chat。

## 4. 模型选择与模型团队

- **参与模型**：右栏或工具栏打开模型池，点选添加；再点一次移除（同名多实例只移除一份）。
- **模型团队**：抽屉里增删成员、改角色、5 档强度、查看连接与调用次数。
- **逐模型停止**：运行中在参与者卡片点停止，只中断该模型，其余继续；最终答案会标注。
- **档位**：Low / Medium / Fast / Max / Ultra，映射推理强度、maxTokens 倍率与温度；运行中修改下一次调用生效，失败自动回滚。
- **裁判**：并行/配合可选裁判；裁判被删光会自动清空引用。
- **Chat ↔ 团队**：运行画布提供「用 Chat 继续」「交给团队」双向切换。

## 5. 连接模型

当前目录覆盖 14 家平台、81 个模型条目。凭证三选一：

| 方式 | 适用 | 说明 |
|---|---|---|
| API Key | 所有平台 | 设置 → 平台 → 粘贴 Key；支持自定义 Base URL |
| 订阅登录 | ChatGPT / Kimi 等 | ChatGPT OAuth；Kimi 设备码（终端与页面都会显示） |
| 本机复用 | 已有 DSH 登录 | 只读 `~/.dsh/.credentials.yaml`，不改原文件 |
| 粘贴 Token | 浏览器会话 | Bearer token / cookie，注意等同账号权限 |

- **中转站**：WorkBuddy 自动发现本机登录态；贾维斯/Devin/OpenRouter/one-api 填 Base URL + Key 后自动拉模型导入。
- **同步模型**：顶部「同步模型」或 `POST /api/models/refresh` 从上游拉取最新目录。
- **购买入口**：设置中各平台提供 API 充值/订阅购买链接。
- **健康状态**：连接失败会在左侧与运行错误中提示；Kimi 设备码过期需重新生成。

## 6. 运行、答案与产物

- 运行画布：每个参与者一张卡片，实时流式输出、思考折叠、耗时/token；顶部阶段条显示并行/互评/综合/裁决。
- 最终答案：可复制、重新综合、继续追问；有裁判时标注裁判。
- **图片**：生图角色产物，实时到达、灯箱查看。
- **3D**：建模角色产出 HTML/Three.js 代码，可实时预览。
- **文件**：模型用 `file name="..."` 代码块交付，服务端转换并落盘：
  - 直接写盘：md/txt/csv/tsv/json/html/svg/xml/yaml/常见代码；
  - 转换：docx（docx）、xlsx（SheetJS）、pptx（PptxGenJS）、pdf（macOS cupsfilter）；
  - 下载/预览：最终答案「文件 n」页签；Chat 在气泡下方；支持中文文件名。
- 运行历史：回看、复制、重跑；可保存为工作流。

## 7. 上下文、记忆、预算

- **上下文洞察**：每次调用的 system/命令/记忆/参考/历史 token 堆叠条、窗口占用、最紧模型提示。
- **记忆**：记忆空间 + 条目（事实/偏好/决策/洞察），中文搜索、启停、按命令召回注入；支持导入 DSH 记忆种子。
- **预算**：单价表（可编辑）、今日/本月/累计、按模型明细、30 天柱状、CSV 导出；日/月上限、80% 预警、单次运行/调用上限、超限拦截、高成本二次确认、省钱模式。
- **附件**：图片/PDF/Word/代码，拖拽或 ⌘V 粘贴，本地解析正文并计入上下文。

## 8. 工作流

- 运行结束后「保存为工作流」，把角色/模型/指令/输入来源固化为步骤；
- 支持串行与并行组、内置模板；运行结果可回看，运行本身也可再保存为模板；
- 适合周报、方案评审、代码审校等重复流程。

---

## 9. 插件中心

- 扫描本机 DSH 插件，标注：**已原生迁移 / 可桥接 / 仅 DSH**；
- 可测试桥接命令（例如 ffmpeg），并在任务中调用；
- 插件能力包括：媒体处理、图像/视频生成、记忆、工作流、模型接入等；
- 新增插件：在 `packages/plugins` 注册适配器，或在设置中配置桥接命令；详见 [插件说明](PLUGINS.md)。
- 插件仅在本机执行；第三方插件的行为与许可证由其作者负责。

## 10. 设置项

- **模型连接**：平台、凭证、测试连接、购买入口；
- **预算**：每日/每月上限、单价表、CSV 导出；
- **代理**：自动读取 macOS 系统代理，可手动填写并测试；
- **性能**：并发 1–8、超时、默认输出 token、流式合并间隔；
- **关键词**：关键词 → 模式/角色/档位/记忆/省钱/裁判 的自动触发规则（支持测试与优先级）；
- **角色**：自定义角色、编辑内置角色、启用/禁用；
- **模型**：自定义模型 ID/上下文/价格；
- **插件**：扫描、桥接测试；
- **数据**：数据目录、导出、清理、关于。

## 11. 常见问题

| 问题 | 处理 |
|---|---|
| 模型 401 / 无响应 | 检查 API Key/订阅是否过期；Kimi 重新生成设备码；代理是否可用 |
| 端口被占用 | 关闭旧实例，或设置 `SUPER_WORK_PORT`；`lsof -iTCP:7788 -sTCP:LISTEN` |
| 页面停在旧版本 | 刷新一次；新构建空闲时会自动刷新 |
| 代理环境 | 设置 → 代理 → 检测系统代理；或手动填 `http://127.0.0.1:12334` |
| 文件转换失败 | 看文件卡片的错误；docx/xlsx/pptx/pdf 仅支持文本级转换 |
| 想清空数据 | 退出应用，备份后删除 `~/.super-work`（不可恢复） |
