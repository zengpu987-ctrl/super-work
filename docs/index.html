快速开始

git clone https://github.com/zengpu987-ctrl/super-work.git
cd super-work
pnpm install
pnpm build:all
pnpm test
pnpm start   # http://127.0.0.1:7788

没有 API Key 也能跑：内置演示模型；连接真实模型在设置里完成。
