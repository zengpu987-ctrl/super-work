# Kimi K3.1 Pro 对 Super Work 的 UI 重设计评审

> 由 Kimi K3.1 Pro（via WorkBuddy）基于 v0.0.1 三张截图（空状态 / 运行态 / 设置）产出，2026-11-18。
> 作为 v0.0.2 前端改版的执行依据；冲突时以产品约束（离线、React+手写 CSS、中文）为准。

## A. 信息架构与首屏布局

- **顶栏 56px**：品牌、当前工作流、连接状态、设置；移除大面积欢迎页，首次引导缩为画布内一张可关闭卡片。
- **工作台工具条 48px**：左侧「并行 / 配合」分段控件；右侧「保存为工作流」「运行记录」。模式切换仅影响后续运行，运行中锁定。
- **三栏布局**：1440 下左栏 200px、右栏 320px、间距 12px，页面左右留白 16px；中间为运行画布。左栏仅放历史、模型连接；右栏仅承担当前运行的编排与诊断。
- **新增功能收拢**：  
  - 计费、记忆、工作流：顶栏「资源」下的独立页面，不挤入首屏。  
  - 中转站导入：模型连接页顶部「导入配置」，支持贾维斯/Devin/WorkBuddy，导入后进入差异确认。  
  - 上下文洞察：右栏「编排 / 上下文」页签。  
  - 生图、3D：最终答案内的产物页签，不新增常驻栏。
- 1200px 左栏收为 48px 图标栏；1024px 右栏改为 360px 抽屉。底部命令台固定，输入区高 72px，运行摘要置于其上方。

## B. 视觉系统

```css
--bg-0:#090B10; --bg-1:#0E1118; --bg-2:#141924;
--line-1:#202633; --line-2:#303949;
--text-1:#E8ECF3; --text-2:#A4AEBE; --text-3:#6F7A8C;
--accent:#6D8DFF; --success:#42B883; --warning:#D9A441; --danger:#E06C75;
--r-sm:6px; --r-md:8px; --r-lg:12px;
```

正文 13px/1.65，辅助信息 12px/1.5，面板标题 14px/600，运行标题 20px/600；数字与代码用系统等宽字体。间距仅用 4/8/12/16/24px；卡片内边距 16px。默认无阴影，抽屉/弹层用 `0 16px 48px #00000066`。渐变只保留主运行按钮，状态不依赖发光。

## C. 关键组件

- **角色编排**：8 个槽位采用两行紧凑列表，每行显示角色、模型数、启停状态；点击展开模型多选与参数。空槽显示「未配置·不会调用」，禁止隐式回退；提供「清空」和预计调用数/成本。
- **参与者卡片**：头部固定 40px，含角色、模型、状态、耗时/token；正文默认展开，流式时自动跟随但允许用户锁定滚动。失败卡保留错误与重试，不重排其他卡片。
- **最终答案**：用一条 2px 顶部强调线替代大面积渐变；页签为「答案 / 图片 n / 代码 n」。图片支持缩略图网格与原图查看；3D 代码提供「代码 / 预览」，预览明确沙箱及离线依赖状态。
- **上下文面板**：按调用列出系统提示、记忆、历史、工具、输入的 token 堆叠条；点击记忆条目可定位来源，标注召回但注入/未注入。

## D. 动效与反馈

状态切换 120ms，抽屉 180ms，仅改变 `opacity/transform`；卡片不移动跳动。运行按钮转为「停止」，阶段条显示当前、完成、失败及耗时；token/成本在调用结束后更新。流式光标克制，完成即消失；`prefers-reduced-motion` 下关闭动画，错误用文字+图标，不只靠颜色。

## E. 最优先的 5 个改动

1. **模式与角色编排前置**：直接支撑 v0.0.2 核心，并杜绝未选模型被调用。  
2. **右栏改为编排/上下文双页签**：容纳诊断信息，不扩大常驻界面。  
3. **最终答案升级为产物容器**：统一文本、生图、3D，避免后续继续堆区域。  
4. **压缩首屏与参与者视觉噪声**：提高运行状态和多结果扫描效率。  
5. **响应式收栏与资源独立页面**：保证 1024 可操作，同时为计费、记忆、工作流留下稳定扩展位。
